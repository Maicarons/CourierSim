## CourierSim UI 适配修复（等比缩放 + 一屏显示 + 顶栏竖条）

- 用户反馈：(1) 主菜单底部启动按钮被截断、被迫加 ScrollContainer 滚动，要求"一屏全显示、不要滚动"；(2) 为什么不做等比缩放；(3) GameScene 顶栏/标签按钮被纵向拉成竖条。
- **根因**：`project.godot` 已是 `window/stretch/mode="canvas_items"` + `aspect="expand"`，等比缩放本来就在，但**主菜单内容的设计高度（≈800px）超过设计视口高度（720px）**，所以无论怎么缩放底部都被裁，才被迫加滚动兜底。GameScene 竖条是 `VBoxContainer` 默认所有子节点 `size_flags_vertical=FILL` 会瓜分额外纵向空间，顶栏/日志/标签栏被拉伸、内部按钮跟着被压成竖条。
- **修复**：
  - `project.godot`：`aspect` 由 `expand` 改 `keep`（保证整屏等比缩放、内容永远完整可见，最多留黑边）。
  - 主菜单：去掉 ScrollContainer 改回 `CenterContainer`；压缩内容到 ≤720：vbox `separation` 12→9、`logo` 容器 130→100、`mode_card` 最小高 130→100（`widgets.gd`）。卡片 `custom_minimum_size` 640→620。
  - `widgets.gd` / `GameScene.gd`：对顶栏卡片、日志、标签栏、stat_tile、icon_button、primary_button、chip 统一设 `size_flags_vertical = SIZE_SHRINK_CENTER`，只让中央地图区 `SIZE_EXPAND_FILL`。
- 经验（Godot 4 UI 适配铁律）：(a) 任何用 `FULL_RECT` + 容器的主界面，内容设计高度必须 ≤ 设计视口高度，否则必然裁切/被迫滚动；(b) 固定尺寸的子面板放进 `VBoxContainer`/`HBoxContainer` 时务必显式 `SIZE_SHRINK_CENTER`，否则会被容器纵向拉伸变形；(c) 想要"任意窗口一屏完整显示"就选 `stretch/aspect="keep"` 而非 `expand`。
- 验证：`godot --headless --editor --quit` EXIT=0；GUI 启动 PID 正常、0 运行错误。
