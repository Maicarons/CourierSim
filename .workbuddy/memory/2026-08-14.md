## CourierSim v0.7 数值平衡 + 工程化（长局模拟驱动）

- **平衡长局模拟** `tools/balance_sim.tscn`：AI 策略自动经营 120 天，输出资金/交付/市占/声誉/评级曲线，`TimeSystem.set_speed(0)` + 每回合 `tick_frame(1.0)` 显式推进车队（headless 下 TimeSystem 真实时间驱动车辆 → 手动 advance_day 车辆不动 → 订单全超时的假象，必须显式推进）。
- **第一轮暴露的真实缺陷**：订单量低于运力 → AI 必破产；声誉崩（惩罚-2/奖励+1 不可恢复）。
- **调优**：`compute_spawn` 站点基数 0.6→0.8；deadline buffer 2→4（国际 4→6）；奖励 `km×(1.5+0.1w)`→`km×(2.2+0.12w)`；超时惩罚 -2.0→-1.5；交付声誉 +1.0→+1.5；VAN km_per_day 480→620；胜利条件 Day≥20→Day≥30。
- **市占蚕食机制**（核心修复）：原模型对手份额只增，玩家市占锁死 ~10%（永远达不到评级/成就门槛）。新增：玩家累计交付按比例蚕食对手份额（`delivered×0.0003`，clamp 0.02，按份额占比分摊），对手日增长 1.5%→1.2%。调优后 120 天曲线：Day60 市占 50%、Day100 94%、声誉 71、Day106 评级 A 通关、不破产。早期资金紧张有挑战、中期口碑回升、后期市占攀升。

- **验证**：smoke_test 全 PASS（成就 4 项、评级 S、存档往返）；headless 0 SCRIPT ERROR。
