## v0.12 核心玩法重构（用户 6 个问题全部修复）

逐项定位与修复方案（参考 G:\workspace	ransroute 设计）：

### 问题 1：时间流速太快（按天跳，车辆不是 24h 运行）
- `TimeSystem`：`SECONDS_PER_DAY=2.5` → 改为 `SECONDS_PER_HOUR=6.0`（用户确认），1 天=144 秒。
- `GameManager`：增加 `hour_of_day` 字段（0-23），新增 `advance_hour()`，车辆 24h 不间断运行。
- `GeoMath.travel_days`：默认 `daily_hours=8.0` → `24.0`；新增 `travel_hours(distance, speed)`。
- 顶栏时间显示：`Day N HH:00`，新增 `hour_changed` 信号。

### 问题 2：车辆瞬移到另一城市
- `Vehicle.start_trip_path(path_m, days)`：接受折线路径数组，沿真实公路折线推进（替代直线插值）。
- `Vehicle._point_at_progress`：按弧长比例在折线取点（替代 lerp），新增 `_polyline_point` 静态助手。
- 订单路线绘制改用真实 OSRM 折线（无数据回退直线）。

### 问题 3：中转/端点站功能完全没体现
- `OrderSystem.spawn_one`：origin/dest 必须两端都已建站或建仓（`served_cities()` 返回已建站点池），网络为空时无跨城订单。

- 站点价格大幅上调：站点 3 千 → 20 万；中转仓 8 千 → 60 万（参考 TransRoute 20 万/250 万级）。

### 问题 4：价格离谱 / 缺少租赁和借贷
- 车辆价格上调 + **新增租赁**：每种车增 `lease_daily=车价×2%`，`Vehicle.owned` 标志，`VehicleSystem.lease/return_lease`，`FinanceSystem` 每日扣日租。

### 问题 5：地图描边错位
- **根因**：terrain.png 是 PIL 按 `bbox` **线性**光栅化，但 `_coastlines` 用**等距圆柱投影**绘制——两套投影在高纬度（韩国 37°N）不一致导致描边漂移。
- 修复：`_coastlines` 改为存**经纬度**（不再预转米制），绘制时用 `_bbox_to_screen(lng_lat)` **线性 bbox 映射**与陆地贴图同源，彻底贴合。
- **路网改为真实 OSRM 折线**：删除旧贝塞尔假路网，新增 `_roads.append({"path_m": path_m})`，画奶油白线+深棕描边（双层）。订单路线同理沿折线绘制。
- `bake_routes.py` 工具烘焙 OSRM（Douglas-Peucker 简化），4 个区域产出 korea/hainan/vietnam 全量 163 条，malaysia 11/21（跨海 OSRM 无路网，自动回退 haversine）。

### 问题 6：参考 TransRoute 用真实路径/里程
- `Region.load_routes()`：懒加载 `src/map/data/regions/<id>_routes.json`，提供 `route_between(a,b)` 返回 `{dist_km, dur_h, path_m}`。
- `Region.real_distance_m/real_duration_h`：OSRM 真实里程/耗时优先，无数据回退 haversine/速度估算。
- `Vehicle.assign_order` 用 `Region.route_between` 的 `path_m` 调用 `start_trip_path`，车辆沿真实公路走向移动。
- `OrderSystem.spawn_one`：deadline 用 OSRM dur_h（精确小时）+ 缓冲小时，distance_days=dur_h/24。

- 订单收益按「吨·公里」重算：基础 45 元/吨·km，min 800。配合 6 万车辆 + 20 万站点 + 60 万仓的价格体系，回本周期合理。

### 关键发现 & 踩坑
- `_coastlines` 之前存的是**米制坐标**（已预 `to_local_meters`），修描边时需改为存**经纬度**，在 `_draw` 里才用 `_bbox_to_screen` 线性映射。
- Godot 4 `min(a, b)` 对 String 报错，必须用 `(a<b)?(a):(b)` 三元或显式比较。
- `var x := min(1, n)`、`var x := max(...)` 返回 Variant，Godot 4.7 严格模式当错误。需用 `var x: int = mini(...)` / `maxi(...)`。
- `headless` 看不到渲染，但用 `get_viewport().get_texture().get_image().save_png()` 在非 headless 跑临时场景脚本可截图验证 UI，肉眼看地图效果极其高效。
