## CourierSim v0.5 可玩闭环增强（评级/存档槽位/多对手/事件扩展）

- 依据路线图 M3「存档完善 + 生涯评级」与 M4「AI 竞争」，继续开发。
- **生涯评级**（`GameManager.rating()`）：声誉(≥80/≥60 → +2/+1) + 市占(≥35%/≥20% → +2/+1) + 总资产(≥150万/≥80万 → +2/+1) → 总分 ≥5=S、≥4=A、≥2=B、其余 C。`total_assets()` = 现金 + 车辆×0.8 + 仓级×5000 + 站×3000；`delivered_count()` 统计已送达。
- **胜负判定**：`_check_game_over()` — 现金<-5万破产失败；生涯模式 Day≥20 且评级 S/A → 通关胜利。`game_over_emitted` 防重复触发（读档重置）；`advance_day()` 在 game over 后不再推进。
- **结算面板** `src/scenes/GameOver.tscn` + `src/ui/GameOver.gd`：胜利🏆/失败💔标题 + 评级或原因 + 8 项统计（天数/现金/总资产/市占/声誉/交付/车队/网络）+ 返回主菜单/再来一局。reason 经 `GameOver.last_reason` 静态传递；进入自动暂停。
- **多槽位存档**：SaveManager 加 `next_free_slot()`(slot_1..9)/`has_slot()`/`slot_label()`；`GameManager.active_slot` 绑定当前游戏槽位（new_game 重置 autosave、load_slot 自动绑定）。主菜单「继续游戏」→ 打开存档槽位面板（公司/Day/区域/时间 + 读取/删除）；「开始新游戏」自动写入空闲槽位；游戏内保存/设置页保存写活跃槽位。
- **竞争系统多对手**（`CompetitorSystem` 重写）：4 家对手池（环宇/极速/顺风/天舟），每 15 天出现 1 家（最多 3），每日自然扩张 + 12% 概率促销事件拉低玩家份额；玩家份额 = 1−Σ对手份额。FinancePanel 改多对手列表展示。
- **事件扩展**：EventSystem 新增 4 事件（新能源补贴 fuel×0.7 / 港口罢工 speed×0.55 / 仓储爆仓 satisfaction×0.72 / 企业大客户 reward×1.5），合计 10 个。
- **i18n**：`tools/merge_strings_v3.py` 合并 46 新键（gameover.*/save.*/menu.saves_title/toast.comp_*/finance.no_comp 等）。
- **踩坑**：(a) 两次 Edit 同一函数区导致旧代码残留（GameManager._check_game_over 重复插入 + summary_dict 后残留 return）→ 修复删残留；(b) `var data := GameManager.to_dict()` Godot 4.7 推断失败 → 显式 `var data: Dictionary`；(c) `print("..." % ("A" if c else "B", x))` 三元+元组解析冲突 → 拆行。
