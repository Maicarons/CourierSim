# 地图系统总览

地图是本作最大的技术亮点与差异化所在：**在真实地理数据上，用像素卡通风格渲染一个可玩的经营世界。**

## 一、设计目标

1. **真实位置**：城市、站点、仓库的相对位置与真实世界一致。
2. **真实路网**：车辆沿真实道路（简化后）行驶，距离与用时真实。
3. **像素表现**：在真实骨架上套 2D 像素瓦片美术，任天堂风格。
4. **可扩展**：首发韩国，后期加载海南、越南、马来西亚等多区域。

## 二、分层架构

地图分三层，解耦数据与表现：

```
┌─────────────────────────────────────────┐
│  表现层（Pixel Rendering）               │
│  TileMapLayer 像素瓦片、建筑精灵、车辆   │
├─────────────────────────────────────────┤
│  逻辑层（Geo-Logic）                     │
│  城市/站点/仓库坐标、路网图、距离矩阵     │
├─────────────────────────────────────────┤
│  数据层（Geo-Data）                      │
│  OSM/Geofabrik 原始数据、烘焙后的资源     │
└─────────────────────────────────────────┘
```

- **数据层**：离线处理真实数据，产出游戏可加载的资源（城市表、路网、距离矩阵）。
- **逻辑层**：游戏运行时使用这些数据做寻路、距离、覆盖计算。
- **表现层**：把逻辑坐标投影到瓦片网格，用像素美术渲染。

## 三、首发区域：韩国

选择韩国作为首发，理由：

1. **规模适中**：全国约 10 万 km²，城市数量可控（首尔、釜山、仁川、大邱、光州、大田、蔚山等），适合首版打磨。
2. **数据完备**：Geofabrik 有 `asia/south-korea-latest.osm.pbf`，OSM 数据质量高。
3. **物流特征鲜明**：首都圈集中、港口城市（釜山/仁川）、高速路网发达，玩法有辨识度。
4. **像素地图友好**：半岛地形轮廓清晰，易于绘制可识别的地图。

## 四、扩展区域

| 阶段 | 区域 | 数据源 | 特点 |
|------|------|--------|------|
| 首发 | 韩国 | `asia/south-korea-latest.osm.pbf` | 主战场 |
| 扩展 1 | 中国海南 | `asia/china` 提取海南省 | 岛屿物流、环岛线 |
| 扩展 2 | 越南 | `asia/vietnam-latest.osm.pbf` | 南北狭长、河内/胡志明双极 |
| 扩展 3 | 马来西亚 | `asia/malaysia-singapore-brunei-latest.osm.pbf` | 半岛+东马、跨海 |

扩展机制详见 [区域切换机制](/map/region-switching)。
