# 阶段划分与里程碑

采用**6 阶段**开发路线，每阶段有明确交付物与验收标准。首版聚焦韩国区域 + 核心玩法闭环。

## 阶段总览

```
M0 立项筹备 → M1 技术验证 → M2 垂直切片 → M3 可玩闭环 → M4 内容填充 → M5 打磨发布
    1-2周        2-3周          4-6周          6-8周         4-6周        2-4周
```

## M0：立项筹备（1~2 周）✅ 完成

| 任务 | 产出 | 状态 |
|------|------|------|
| 技术选型确认 | Godot 4.x + GDScript + VitePress | ✅ |
| 仓库初始化 | GitHub 仓库 + AGPL + .gitignore + CI | ✅ |
