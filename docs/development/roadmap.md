# 阶段划分与里程碑

采用**6 阶段**开发路线，每阶段有明确交付物与验收标准。首版聚焦韩国区域 + 核心玩法闭环。

## 阶段总览

```
M0 立项筹备 → M1 技术验证 → M2 垂直切片 → M3 可玩闭环 → M4 内容填充 → M5 打磨发布
    1-2周        2-3周          4-6周          6-8周         4-6周        2-4周
```

## M0：立项筹备（1~2 周）

**目标**：确定方案、搭好骨架。

| 任务 | 产出 |
|------|------|
| 技术选型确认 | 引擎/插件/工具链定稿 |
| 仓库初始化 | GitHub 仓库 + AGPL + .gitignore + CI |
| 文档站搭建 | VitePress 骨架 + 本规划文档 |
| 地理数据调研 | 韩国数据可用性验证 |

**验收**：仓库可 clone、文档可构建、韩国 PBF 下载成功。

## M1：技术验证（2~3 周）

**目标**：验证关键技术风险。

| 任务 | 产出 |
|------|------|
| 地理烘焙管线 | 韩国 cities/road_graph/distance_matrix |
| 坐标转换 | GeoUtils + 投影正确性验证 |
| 地图渲染原型 | TileMapLayer 显示韩国像素地图 |
| 路网寻路原型 | AStar2D 车辆沿路网移动 |
| 存档原型 | JSON 读写 + 版本迁移 |

**验收**：地图正确显示韩国轮廓与城市，车辆能沿真实路网移动，存档可读写。

## M2：垂直切片（4~6 周）

**目标**：跑通最小可玩闭环（一条完整经营链路）。

| 任务 | 产出 |
|------|------|
| 站点系统 | 建站 + 覆盖 + 货量 |
| 车辆系统 | 购车 + 分配 + 调度 |
| 仓库系统 | 建仓 + 容量 + 转运 |
| 订单货流 | 生成 + 状态机 + 签收 |
| 经济系统 | 收入/成本/现金 |
| 时间系统 | tick + 暂停/调速 |
| 基础 UI | HUD + 各管理面板 |

**验收**：玩家能"建站→买车→建仓→接单→运输→收款"完成闭环。

## M3：可玩闭环（6~8 周）

**目标**：补齐核心玩法，形成完整游戏。

| 任务 | 产出 |
|------|------|
| 市场宣传 | 知名度 + 活动 + 定价 |
| 员工系统 | 招聘 + 岗位 + 效率 |
| 科技树 | 研发 + 解锁货种 |
| 突发事件 | 事件 + 应对 |
| 生涯模式 | 章节 + 目标 + 评级 |
| 沙盒模式 | 自由参数 + 成就 |
| 存档完善 | 多槽位 + 自动存档 |

**验收**：两个模式可玩，核心系统全部接入，形成"增长飞轮"体验。

## M4：内容填充（4~6 周）

**目标**：扩充内容与美术，打磨品质。

| 任务 | 产出 |
|------|------|
| 美术资源 | 全量精灵/UI/音效 |
| 特殊货种 | 冷链/医药/危险品 |
| AI 竞争 | 对手公司 |
| 区域扩展 | 海南（或越南）数据 |
| 数值平衡 | 成长曲线调优 |

**验收**：内容完整，美术到位，数值平衡初版。

## M5：打磨发布（2~4 周）

**目标**：稳定、优化、发布。

| 任务 | 产出 |
|------|------|
| 性能优化 | 60 FPS 达标 |
| 测试修复 | Bug 清零 |
| 本地化 | 中文完整 |
| 打包发布 | 桌面三平台构建 |
| 开源发布 | GitHub Release + 文档完善 |

**验收**：稳定发布 v1.0，文档完整。
