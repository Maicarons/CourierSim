# 愿景与设计支柱

## 一句话定位

**《CourierSim · 快递王国》**是一款 2D 像素卡通、任天堂复古风格的**快递公司模拟经营游戏**。玩家从一辆破旧面包车和一间社区站点起步，通过购置车辆、建设中转仓库、铺设覆盖站点、市场推广与精细化运营，逐步成长为覆盖多国、多区域的物流帝国。

与市面上"点击收钱"的放置类快递手游不同，本作强调**空间规划 + 网络拓扑 + 调度优化**的策略深度：每一个站点、每一辆车的去向、每一条线路的时效，都由玩家亲手决定，且都建立在**真实地图数据**之上。

## 设计支柱（Design Pillars）

1. **真实地理骨架（Real-Geo Skeleton）**
   城市坐标、区域边界、路网、距离与用时均来自真实数据（OpenStreetMap / Geofabrik / OSRM）。玩家看到的地图不是凭空捏造，而是可辨认的现实区域。这是本作区别于大多数模拟经营游戏的核心差异点。

2. **像素卡通外壳（Pixel-Cute Skin）**
   在真实地理之上，用 2D 像素美术 + 明亮配色 + 圆润造型包装成任天堂风格。真实的城市相对位置、真实的路网拓扑，但视觉上是卡通化的、低门槛的、亲切的。

3. **网络即玩法（Network is the Game）**
   核心乐趣来自"搭建并优化运输网络"：站点 ↔ 中转仓库 ↔ 站点（轴辐式 hub-and-spoke）的拓扑设计、线路调度、容量平衡。玩家不是点按钮，而是画一张不断演化的物流网络。

4. **可见的因果反馈（Visible Causality）**
   每个决策都能在画面与数据面板上看到结果：加一辆车、改一条线、投一次广告，货量、时效、满意度、利润随之变化。目标是把复杂的物流原理用直观、可玩的方式呈现。

5. **渐进式复杂度（Gentle Complexity）**
   生涯模式通过关卡目标引导玩家逐步解锁新系统；沙盒模式则一次性开放全部，供深度玩家自由经营。两条曲线满足轻度和重度玩家。

## 目标平台与引擎

| 项 | 选择 |
|----|------|
| 引擎 | Godot 4.x（以 4.3/4.4 稳定版为基线） |
| 语言 | GDScript（核心逻辑），性能热点可下放 C# / GDExtension(Rust) |
| 目标平台 | Windows / macOS / Linux 桌面首发，后续 Web(HTML5) 与移动端 |
| 美术 | 2D 像素（16×16 / 32×32 瓦片），TileMapLayer + TileSet |
| 分辨率 | 基础 960×540，UI 自适应缩放 |

## 与 TransRoute 的关系

本项目直接继承并升华了前作 [TransRoute（物流大亨）](https://github.com/) 的核心资产：

- **地理数据方案**：城市目录、Geofabrik PBF 下载、OSRM 路网构建、Haversine 距离、Nominatim 地理编码，全部可复用（详见 [参考项目：TransRoute](/overview/reference)）。
- **物流经营模型**：车辆、线路、货池分配、评分、金融等实体与公式，作为数值设计的起点。
- **技术栈经验**：VitePress 文档、Docker/OSRM 部署、CI 流水线等工程实践。

区别在于：TransRoute 是浏览器 Web 游戏（React + MapLibre + Go），本作是 **Godot 原生 2D 游戏**，主打像素卡通表现与单机沉浸式经营。
