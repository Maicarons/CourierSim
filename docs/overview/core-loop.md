# 核心循环（Core Loop）

## 一句话循环

**接单 → 规划网络 → 运输配送 → 收款盈利 → 扩张再投资**，循环往复，规模与复杂度螺旋上升。

## 循环拆解

```
          ┌──────────────────────────────────────────────┐
          │                                                │
          ▼                                                │
   ┌─────────────┐    ┌──────────────┐    ┌────────────┐  │
   │  接收订单    │───▶│  规划与调度   │───▶│  执行运输   │  │
   │ (货量生成)   │    │ (车辆/线路)   │    │ (时效/损耗) │  │
   └─────────────┘    └──────────────┘    └────────────┘  │
          ▲                                     │         │
          │                                     ▼         │
          │                              ┌────────────┐   │
          └──────────── 再投资/扩张 ◀─────│  结算收款   │───┘
                                         │ (利润/评分)  │
                                         └────────────┘
```

## 三个时间尺度

本作采用**小时制离散 tick 模拟**（v0.12）：1 游戏小时 = 6 真实秒，车辆 24 小时不间断运行（详见[时间系统](/gameplay/time)）。

| 尺度 | 粒度 | 内容 |
|------|------|------|
| 实时 | 逐帧 | 车辆沿折线行驶动画、UI 交互、镜头移动 |
| 小时级 | 每 6 秒（1×） | `advance_hour`：车辆位置推进、到达/出发判定 |
| 天级 | 每 24 小时 | `advance_day`：订单生成、财务结算、评分更新、事件触发 |

玩家可暂停 / 1× / 2× / 4× 调速，生涯与沙盒共享同一模拟内核。

## 增长飞轮

1. **覆盖更多**：新建站点 → 覆盖新区域 → 货量上升。
2. **跑得更快**：升级车辆 / 优化线路 → 时效提升 → 评分上升 → 分到更多货。
3. **装得更多**：升级仓库容量 / 车辆载重 → 单位成本下降 → 利润上升。
4. **赚得更多**：市场推广 → 品牌知名度 → 货量溢价。
5. **再投资**：利润 → 新车 / 新仓库 / 新站点 / 研发 → 回到 1。

设计目标是让玩家在每一步都感受到"投入 → 可见回报"，但引入**容量瓶颈、时效压力、资金约束**防止无脑扩张。

## 决策类型（玩家日常要做的事）

- **空间决策**：站点/仓库建在哪？覆盖哪些区域？
- **资源决策**：买什么车？几辆？分给哪条线？
- **调度决策**：车辆走什么路线？中转还是直达？
- **价格决策**：运价定多高？是否促销？
- **投资决策**：钱投市场、研发、扩容量还是扩覆盖？
- **风险决策**：是否贷款？是否接高风险加急单？

## 失败与压力

- 现金断流 → 可申请贷款，信用差则被拒 → 破产清算（生涯模式结束，沙盒可继续）。
- 满意度持续走低 → 货量被竞争对手抢走。
- 时效违约 → 罚款 + 评分下降。
- 仓库爆仓 / 车辆闲置 → 隐性成本上升。

压力点用于制造"经营张力"，让玩家不是单纯堆数值，而是持续权衡取舍。
