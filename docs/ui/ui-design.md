# CourierSim UI / UX 设计规范（v2 重构）

> 适用版本：v0.4.0 · 设计基准：《双点医院》《监狱建筑师》等主流管理模拟经营
> 重构目标：信息层级清晰、操作直观、新玩家无需文字也能上手。

## 一、设计原则

1. **图标驱动 + 悬停提示**：所有交互按钮优先使用图标，鼠标悬停时显示卡通气泡说明功能。
2. **顶栏 + Tab + 内容三段式**：状态持久可见、功能按模块分组、内容即查即用。
3. **全屏沉浸**：主菜单、关于、设置各自为独立全屏页面，无嵌套、无模态。
4. **渐进引导**：生涯模式用对白+目标卡片逐章教学，不一次性灌输。
5. **真实世界地图**：自然地理轮廓 + 真实城市位置 + 风格化卡通地形。

## 四、组件库（widgets.gd）

| 工厂方法 | 用途 |
|---|---|
| `card(bg, border, radius, pad)` | 通用卡片 |
| `icon_button(text, icon, cb, tooltip)` | 图标+文字按钮（带 tooltip 可选） |
| `icon_only_button(icon, tooltip, cb, size)` | 纯图标按钮（tab 栏/工具栏） |
| `attach_tooltip(c, text)` | 给任意控件注册 tooltip |
| `primary_button(text, color, cb)` | 强饱和大按钮（开始/确认） |
| `info_row(icon, title, subtitle, actions)` | 列表行（左图标+右操作） |
| `header(parent, text)` | 分节标题+分隔线 |
| `status_chip(text, color)` | 状态徽章（顶栏用） |
| `mode_card(icon, title, desc, cb)` | 模式选择卡片（带选中态） |

## 五、Tooltip 规范

- 延迟 0.32 秒显示
- 光标右下偏移 14×18 px
- 接近屏幕边界时自动翻转（左下或上）
- 深棕黑底 + 橙色边 + 卡通阴影
- 单行/多行自适应
- 注册时机：按钮创建时或构造完成后

## 七、地图系统规范

- **数据源**：Natural Earth 50m（陆地）+ 区域 JSON（城市）
- **加载方式**：运行时零网络；从 `res://src/map/data/regions/` 读 PNG + JSON
- **重绘流程**：
  1. 海洋底色（浅天蓝）
  2. 陆地贴图（按 bbox 拉伸预渲染 PNG）
  3. 海运虚线（港口之间）
  4. 陆路曲线（最近 2 邻，< 320 km）
  5. 海岸线描边
  6. 城市节点 + 名称气泡
  7. 仓库/站点图示
  8. 订单流光线（仅进行中）
  9. 车辆精灵
  10. 悬停/选中高亮
  11. 图例

- **交互**：
  - 滚轮缩放（0.5x ~ 8x）
  - 左键拖拽平移
  - 悬停高亮 + Tooltip
  - 点击城市 → 选中 → 显示信息卡 + 操作栏（建仓/建站/升级/宣传）

## 八、可访问性 & 体验细节

- 所有图标按钮都有 tooltip，新玩家无需文字就能理解
- 主操作（开始/确认）使用绿色强饱和色，避免误关
- 退出按钮用红色 + 显眼图标（电源），但放在菜单底部降低误触
- 设置页进入自动暂停游戏时间，离开由 GameScene 自行决定恢复
- 任何长时间对白期间，遮罩拦截地图点击，避免误操作
- 剧情对白支持打字机效果（28 字符/秒），点「继续」可跳过动画
- 中英切换实时生效（rebuild 当前界面）
