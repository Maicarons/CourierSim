# 地图资源清单

地图资源是"真实地理 + 像素表现"的结合点，来自离线烘焙管线。

## 一、地形瓦片（Terrain Tiles）

| 瓦片 | 说明 | 优先级 |
|------|------|--------|
| 草地/平原 | 基底 | P0 |
| 道路（4 级） | 高速/国道/次干/城市路 | P0 |
| 水体 | 海/河/湖 | P0 |
| 城市建成区 | 密集区基底 | P0 |
| 工业区 | 仓库候选地 | P0 |
| 商业区 | 高需求 | P0 |
| 森林/山地 | 地形阻隔 | P1 |
| 港口/机场 | 跨境节点 | P2 |
| 边界 | 行政区描边 | P2 |

## 二、底图（Base Map）

- **像素化底图**：由真实矢量（道路/水系/边界）烘焙为像素瓦片。
- **开发期参考底图**：真实地图瓦片（MapTileProvider）对照校准位置。

## 三、区域数据包（每区域）

| 文件 | 内容 | 大小量级 |
|------|------|---------|
| `cities.json` | 城市目录 | KB |
| `road_graph.json` | 路网图 | MB |
| `distance_matrix.json` | 距离矩阵 | MB |
| `demand_grid.json` | 需求密度 | MB |
| `tileset.res` | 瓦片集 | MB |
| `poi.json` | POI | KB |

## 四、覆盖/规划可视化资源

| 资源 | 说明 |
|------|------|
| 覆盖圆（半透明） | 站点覆盖范围 |
| 等时圈 | 仓库辐射（进阶） |
| 路线高亮 | 车辆调度线路 |
| 区域边界高亮 | 选中区域 |

## 五、地图标注

- 城市名标注（像素字体）。
- 站点/仓库图标（精灵）。
- 货量热力（可选，需求可视化）。

## 六、分辨率与缩放层级

| 层级 | 像素/米 | 显示内容 |
|------|---------|---------|
| 全国 | 0.02 | 城市点 + 干线 |
| 区域 | 0.1 | 道路网 + 站点 |
| 城市 | 0.5 | 街道 + 建筑细节 |

- 相机缩放时切换 LOD（层级细节），远看只显示城市，近看显示道路/建筑。

## 七、数据来源与许可

- 地图数据 OSM（ODbL），需署名（见 [许可](/development/license)）。
- 像素瓦片为自产衍生作品，遵循 ODbL 派生条款。
