# 素材总览与美术风格

## 一、美术风格定义

**任天堂风 2D 像素卡通**，参考：宝可梦（Pokémon）、动物森友会（Animal Crossing）、星露谷物语（Stardew Valley）的视觉语言。

### 风格关键词

- **像素**：16×16 / 32×32 瓦片，清晰像素（非模糊平滑）。
- **明亮配色**：高饱和、温暖、明快，避免暗沉写实。
- **圆润造型**：Q 版比例，头身比夸张，亲和可爱。
- **扁平光影**：简单明暗两阶 + 描边，干净利落。
- **低多边形感**：像素粒度下保持简洁，细节适度。

### 配色原则

| 用途 | 配色倾向 |
|------|---------|
| 地面/道路 | 柔和暖灰、米色 |
| 水体 | 明亮蓝绿 |
| 建筑 | 高饱和点缀色（红/橙/蓝/绿） |
| UI | 白底 + 深色文字 + 主题色按钮 |
| 车辆 | 明快纯色车身 + 浅色车窗 |

## 二、像素规格

| 项 | 规格 |
|----|------|
| 基础瓦片 | 32×32 px |
| 角色/车辆 | 32×32 ~ 64×32 px |
| 建筑 | 32×32（单格）~ 128×96（大仓） |
| UI 图标 | 16×16 / 24×24 |
| 字体 | 像素中文字体（如 Zpix、fusion-pixel） |

## 五、AI 辅助

- 可用 AI 生成参考概念图（风格统一参考），但**成品像素画需人工精修**保证品质与风格一致。
- 像素动画（车辆行驶、建筑动效）建议手绘关键帧，AI 只做灵感/配色参考。
