## 七、图集（Atlas）组织

- 同类精灵打成一个图集（如 `vehicles.png`、`buildings.png`），减少纹理切换。
- 用 Godot `AtlasTexture` 或直接 `TileSet` / `SpriteFrames` 管理。

## 九、优先级说明

- **P0**：MVP 必需，第一阶段交付。
- **P1**：核心体验增强，第二阶段。
- **P2**：扩展内容，第三阶段。
- **P3**：锦上添花，可后置。
