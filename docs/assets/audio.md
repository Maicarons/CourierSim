# 音效与音乐清单（Audio）

## 一、音乐（BGM）

| 曲目 | 场景 | 风格 | 优先级 |
|------|------|------|--------|
| 主菜单主题 | 主菜单 | 轻快、温暖 | P0 |
| 经营主循环 BGM | 游戏内 | 舒缓、循环 | P0 |
| 扩张/成就变奏 | 重大扩张后 | 上扬、激励 | P1 |
| 竞争/危机 BGM | 事件触发 | 紧张 | P2 |
| 结算/报表 BGM | 财务面板 | 理性、平静 | P2 |

- 风格统一为**像素游戏感 + 轻爵士/吉卜力式温暖**，循环无痕。
- 授权：自产或购买免版税音源（记录许可）。

## 二、音效（SFX）

| 类别 | 音效 | 优先级 |
|------|------|--------|
| UI | 点击、悬停、确认、取消、弹窗 | P0 |
| 资金 | 收款（金币声）、扣款 | P0 |
| 建造 | 建站/建仓、升级 | P1 |
| 车辆 | 引擎启动、行驶（低频循环）、喇叭 | P1 |
| 货物 | 装卸、分拣、包裹放置 | P1 |
| 反馈 | 成功（提示音）、失败（错误音） | P0 |
| 事件 | 警告、天气（雷/雨） | P2 |
| 通知 | 消息到达、成就解锁 | P1 |

## 三、空间音频

- 车辆引擎声用 `AudioStreamPlayer2D`，随车辆位置衰减，营造世界感。
- 仓库分拣声用 `AudioStreamPlayer2D` 挂在仓库节点。

## 四、音量控制

- 分级：主音量 / BGM / SFX / 环境。
- 存 `user://settings.cfg`（ConfigFile）。

## 五、音频规格

| 项 | 规格 |
|----|------|
| 格式 | OGG（Vorbis）为主，WAV 备用 |
| 采样率 | 44.1 kHz |
| BGM | 循环无缝，2~4 分钟 |
| SFX | < 2 秒，短促 |

## 六、工具与来源

| 工具 | 用途 |
|------|------|
| Bosca Ceoil | 免费像素风音乐制作 |
| LMMS / FL Studio | 编曲 |
| bfxr / jsfxr | 8-bit 音效生成 |
| Audacity | 音频编辑 |
| 免版税音源库 | freesound、OpenGameArt（注意许可） |
