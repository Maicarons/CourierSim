# UI 素材清单

## 一、UI 设计原则

- **像素风统一**：面板圆角、描边、图标均为像素风格。
- **信息密度适中**：经营面板信息多，但分层展示，避免堆砌。
- **中文友好**：像素中文字体（Zpix 等），保证可读性。
- **主题色**：主色（橙/蓝）贯穿按钮与强调。

## 五、字体

| 字体 | 用途 | 许可 |
|------|------|------|
| Zpix（最像素） | 正文/数字 | 开源（OFL 类） |
| fusion-pixel | 备选 | 开源 |
| 思源黑体（非像素） | 大段文字兜底 | OFL |

- 数字用等宽像素字体，保证报表对齐。

## 六、图标规范

- 统一 24×24 网格，像素对齐。
- 线宽 1px，配色 2~3 色，简洁辨识。

## 七、九宫格（9-patch）

面板背景用 Godot `NinePatchRect`，保证任意尺寸拉伸不变形（像素风需注意拉伸时的像素对齐）。

## 八、主题（Theme）

- 用 Godot `Theme` 资源统一管理组件样式，一改全改。
- 暗色/亮色两套主题（默认亮色，像素游戏偏亮色）。

## 九、本地化

- 中文首发，预留 i18n（CSV/JSON 词条），结构上支持多语言。
- 所有 UI 文案走本地化 key，不硬编码。
