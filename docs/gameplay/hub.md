# 中转仓库（Hub）

中转仓库是物流网络的**中枢节点**，承担货物集散、分拣、转运职能，是网络效率的关键瓶颈。

## 一、仓库属性

```
Hub {
  id: String
  name: String
  position: Vector2       // 地图坐标（投影后）
  geo: {lng, lat}         // 真实经纬度
  level: int              // 1~5
  capacity_kg: float      // 仓储容量（公斤）
  throughput_per_day: float // 日处理能力（分拣吞吐）
  parking: int            // 车辆泊位
  staff_slots: int        // 员工岗位数
  area_radius: float      // 覆盖半径
  cost_per_day: float     // 日运营成本
}
```

## 二、选址（Siting）

选址是仓库玩法最具策略性的部分：

- **候选点**：地图上预置的"物流园区/工业用地"格点（由真实城市工业区/物流园数据标注）。
- **选址考量**：
  - **地理中心性**：位于所服务站点的几何/路网中心，减少总转运距离。
  - **地价**：市中心地价高但靠近货源地；郊区地价低但距离远。
  - **交通可达性**：靠近主干道/高速公路（真实路网）可提速。
  - **扩展空间**：预留升级用地。
- **评估工具**：提供"覆盖分析"——选中某地，高亮显示其覆盖半径内的站点与预估货量。

## 三、升级

| 等级 | 仓储容量 | 日吞吐 | 泊位 | 解锁能力 |
|------|---------|--------|------|----------|
| 1 | 10 t | 5 t/日 | 2 | 基础集散 |
| 2 | 25 t | 12 t/日 | 4 | 分拣自动化 I |
| 3 | 50 t | 30 t/日 | 8 | 冷链仓储 |
| 4 | 100 t | 70 t/日 | 15 | 自动化分拣 II、危险品 |
| 5 | 200 t | 150 t/日 | 30 | 智能仓储、跨境分拨 |

升级消耗资金 + 时间（建造期），期间容量不变，考验规划节奏。

## 四、容量管理

容量是仓库玩法的核心约束，需持续平衡：

- **仓储容量**：存不下则货物**滞留/溢出**，溢出货物罚款并损害满意度。
- **吞吐能力**：每天最多处理 X 吨，超过则**积压**，积压越久时效越差。
- **泊位**：车辆无处停靠则无法发车/卸货。
- **负载率**：仓库利用率 = 实际处理量 / 吞吐能力，过高（>90%）触发拥堵预警。

**玩家应对手段**：扩容升级、新建分仓、优化调度削峰、提高分拣效率（科技/员工）。

## 五、转运流程

```
货物到站 → 站点集货 → 干线运输 → 到 Hub 分拣 → 干线运输 → 目标站点 → 派送
```

- Hub 内部模拟"分拣"环节：货物进入后需等待 `处理时间 = 货量 / 吞吐能力`，再进入下一程。
- **多级 Hub**：后期可建设区域枢纽 + 全国枢纽两级（区域 Hub → 全国 Hub → 区域 Hub），对应真实快递网络的"干支线"结构。

## 六、技术实现要点

- `HubManager` 管理所有仓库实例与升级状态。
- 仓库在地图上为**可交互建筑节点**（点击弹出管理面板）。
- 覆盖分析用**圆覆盖 / 路网等时圈**两种模式（简单版先做圆，进阶做路网距离）。
- 分拣排队用 `Array[Shipment]` 队列 + 每日吞吐上限模拟，避免逐单物理模拟的性能开销。

```gdscript
# 每日吞吐模拟（示意）
func process_daily():
    var capacity = throughput_per_day
    for shipment in inbound_queue:
        if capacity <= 0:
            shipment.delay_days += 1   # 积压
            continue
        var units = shipment.weight_kg
        if units <= capacity:
            capacity -= units
            outbound_queue.append(shipment)
            inbound_queue.erase(shipment)
        else:
            break
```
