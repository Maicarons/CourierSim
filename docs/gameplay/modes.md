# 游戏模式（Game Modes）

## 一、生涯模式（Career Mode）

引导式教学，逐步解锁系统，适合新玩家。

### 结构

- **章节化关卡**：每章一个经营目标（如"3 个月内让首尔西站日处理 500 件"）。
- **渐进解锁**：车辆 → 站点 → 仓库 → 市场 → 员工 → 科技 → 竞争，逐章引入。
- **引导**：任务指引 + 目标高亮 + 新手提示，逐步放权。

### 目标设计（示例章节）

| 章节 | 目标 | 解锁系统 |
|------|------|----------|
| 1 起家 | 建成首个站点，日收 50 件 | 站点 |
| 2 第一辆车 | 购置面包车并开通首条线路 | 车辆 |
| 3 集散中心 | 建成首个中转仓库 | 仓库 |
| 4 覆盖扩张 | 覆盖 3 个城市区域 | 覆盖规划 |
| 5 打响名号 | 知名度达 30 | 市场宣传 |
| 6 人尽其用 | 招聘 10 名员工 | 员工 |
| 7 科技赋能 | 研发自动分拣 | 科技 |
| 8 冷链蓝海 | 开通冷链线路盈利 | 特殊货种 |
| 9 商海沉浮 | 在竞争中保持市场份额 | AI 竞争 |
| 10 跨国巨头 | 扩展至第二国家 | 区域切换 |

- **评级**：每章按完成度给 1~3 星，鼓励反复优化。
- **失败重试**：破产可重开本章，无永久惩罚。

## 二、沙盒模式（Sandbox Mode）

自由经营，无目标限制，适合深度玩家。

- **全系统开放**：车辆、仓库、站点、市场、员工、科技、事件、AI 竞争全部可用。
- **自由参数**：初始资金、AI 对手数量与难度、事件频率、地图区域可自定义。
- **自由扩张**：无章节限制，可自由切换区域（韩国 → 海南 → 越南 → 马来西亚）。
- **成就系统**：里程碑式成就（"拥有 100 辆车""覆盖全国"）提供软目标。

## 三、共享内核

两种模式共享同一套模拟内核（`SimEngine`），仅外层目标/解锁逻辑不同：

```
SimEngine（共享）          Mode 层（差异）
┌─────────────────┐      ┌──────────────────┐
│ DemandSystem    │      │ CareerController  │ ← 章节/解锁/评级
│ FlowSystem      │◀─────│ SandboxController │ ← 参数/成就/自由切换
│ FinanceSystem   │      └──────────────────┘
│ FleetManager ...│
└─────────────────┘
```

这保证玩法数值一致，维护成本最低。

## 四、未来可选模式

- **挑战模式**：限时目标（"30 天内盈利 100 万"），排行榜。
- **剧情模式**：带故事线的经营（如家族快递复兴记）。
- **多人/异步**：参考 TransRoute 多人版，长期愿景。
