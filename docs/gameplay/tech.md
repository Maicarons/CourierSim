# 科技研发（Research & Tech）

科技树提供长线成长目标，解锁新货种、降本增效，是后期深度来源。

## 一、科技树分支

| 分支 | 方向 | 示例 |
|------|------|------|
| 车辆科技 | 降油耗、提速、增载 | 新能源车、自动驾驶辅助 |
| 仓储科技 | 提升分拣/容量 | 自动分拣系统、智能仓储 |
| 信息技术 | 优化路由/定价 | 智能调度、动态定价 |
| 冷链科技 | 解锁生鲜/医药 | 冷链保温、温控溯源 |
| 绿色科技 | 降碳/合规 | 环保包装、碳积分 |

## 二、解锁机制

- **前置依赖**：部分科技需前置科技解锁（如"冷链运输"前置"保温包装"）。
- **解锁新货种**：科技解锁是**新利润增长点**的主要入口（生鲜、医药、危险品）。
- **研发投入**：消耗资金 + 研发时间（可多线并行，受研发中心等级限制）。

## 三、效果量化

每个科技给**可叠加的系数**：

```
总效率 = 基础 × (1 + Σ 科技加成) × 员工系数 × 设施等级系数
```

例如：油耗 = 基础油耗 × (1 - 车辆科技省油 15%) × (1 - 员工驾驶技能加成)。

## 四、技术实现要点

- 科技树用**数据驱动**的 JSON 定义（节点、依赖、成本、效果），`TechSystem` 读取。
- 效果以"全局修正量"挂在各系统上，避免硬编码 if-else。

```json
{
  "id": "auto_sort_2",
  "name": "自动分拣系统 II",
  "requires": ["auto_sort_1"],
  "cost": 500000,
  "days": 15,
  "effects": { "hub_throughput_mult": 0.25 }
}
```
