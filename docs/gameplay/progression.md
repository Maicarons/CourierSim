# 生涯评级 · 存档槽位 · 竞争系统（v0.5）

> 适用版本：v0.5 · 补齐 M3「存档完善 / 生涯评级」与 M4「AI 竞争」的交付。

## 一、生涯评级系统

### 评分规则（`GameManager.rating()`）

| 维度 | 条件 | 得分 |
|---|---|---|
| 声誉 | ≥ 80 / ≥ 60 | +2 / +1 |
| 市场占有率 | ≥ 35% / ≥ 20% | +2 / +1 |
| 总资产 | ≥ 150 万 / ≥ 80 万 | +2 / +1 |

| 总分 | 评级 |
|---|---|
| ≥ 5 | S |
| ≥ 4 | A |
| ≥ 2 | B |
| 其余 | C |

- 总资产 = 现金 + 车辆购置成本×0.8 + 仓库等级×5000 + 站点×3000
- 评级在结算面板（`GameOver.tscn`）展示

### 胜负判定（`GameManager._check_game_over()`）

| 条件 | 结果 |
|---|---|
| 现金 < -50000 | 失败（破产） |
| 生涯模式 && Day ≥ 20 && 评级 ∈ {S, A} | 胜利（称霸区域） |
| 其余 | 继续经营 |

- `game_over_emitted` 防重复触发；读档时自动重置
- `advance_day()` 在 game over 后不再推进，结算页静止

## 二、存档槽位系统

### 槽位模型

| 槽位 | 用途 |
|---|---|
| `slot_1` ~ `slot_9` | 手动/新建存档（最多 9 个） |
| `autosave` | 兼容旧版本保留 |

### 交互

- **主菜单 → 继续游戏**：打开存档槽位面板，列出所有槽位（公司名 / Day / 区域 / 保存时间），可读取或删除
- **主菜单 → 开始新游戏**：自动写入 `next_free_slot()`（不覆盖已有存档），并绑定为活跃槽位
- **游戏内保存**（顶栏 💾）：保存到当前活跃槽位
- **设置 → 存档**：立即保存（活跃槽位）、读取、删除任意槽位

### 实现

- `SaveManager`：`next_free_slot()` / `has_slot()` / `slot_label()` / `list_slots()` 等
- `GameManager.active_slot`：当前游戏绑定的槽位（`new_game` 重置为 autosave；`load_slot` 自动绑定）
- 读取存档后 `game_over_emitted` 重置，允许重新判定胜负

## 三、竞争系统（多对手）

- 对手池：环宇速运 / 极速物流 / 顺风快达 / 天舟速递（中英双语）
- 每 15 天出现一个新对手（最多 3 家），初始份额 6%~11%
- 对手每日自然扩张（份额 ×1.02）+ 积累资金
- **促销事件**：每日 12% 概率随机对手发起促销，玩家份额临时下降 2%~5%
- 玩家份额 = 1 − Σ对手份额（归一化 ≤ 0.95）
- 财务页签展示每个对手及其份额；`player_share()` 供 UI / 评级 / 教程共用

## 九、数值平衡（v0.7 · 长局模拟驱动）

### 工具

`tools/balance_sim.tscn`：AI 策略自动经营 120 天，输出资金/交付/市占/声誉/评级曲线。
`tools/smoke_test.tscn`：全功能无头回归。

### 第一轮发现（全部是真实缺陷，非模拟问题）

1. **headless 模拟车辆不动**：车辆移动由 TimeSystem 按真实时间驱动，手动 `advance_day()` 不推进车队 → 模拟里订单全超时。修法：模拟内 `tick_frame(1.0)` 显式推进。
2. **订单量低于运力 → 资金持续失血**：`compute_spawn` 站点基数 0.6 太低，AI 必破产。
3. **声誉崩塌**：超时惩罚 -2、成功仅 +1，口碑无法恢复。

### 调优参数（v0.7）

| 参数 | 原值 → 新值 | 效果 |
|---|---|---|
| `compute_spawn` 站点基数 | 0.6 → 0.8 | 订单量匹配运力 |
| 订单 deadline buffer | 2→4（国际 4→6） | 减少超时 |
| 订单奖励 | `km×(1.5+0.1w)` → `km×(2.2+0.12w)` | 覆盖固定成本 |
| 超时声誉惩罚 | -2.0 → -1.5 | 口碑可恢复 |
| 交付声誉奖励 | +1.0 → +1.5 | 服务好口碑涨 |
| 面包车日里程 | 480 → 620 km | 运力提升 |
| **市占蚕食机制** | （新增）`delivered×0.0003`，按份额比例从对手处抢份额 | 玩家交付→市占可突破 10% 天花板 |
| 对手日增长 | 1.5% → 1.2% | 配合蚕食机制 |
| 胜利条件 | Day≥20 → Day≥30 | 防止前期速胜 |

### 调优后 120 天曲线（AI 基准）

```
Day20 资金 4.9万 交付 20 市占 28% 声誉 58
Day60 资金 3.2万 交付108 市占 50% 声誉 65
Day100 资金 2.2万 交付210 市占 94% 声誉 71
Day106 → 评级 A 通关（不破产）
```

- 早期资金紧张（有挑战）→ 中期口碑回升 → 后期市占攀升，成长弧线健康
- AI 基准 106 天 A 级通关；玩家合理操作应更早或更高
