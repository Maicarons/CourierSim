# 生涯评级 · 存档槽位 · 竞争系统（v0.5）

> 适用版本：v0.5 · 补齐 M3「存档完善 / 生涯评级」与 M4「AI 竞争」的交付。

## 一、生涯评级系统

### 评分规则（`GameManager.rating()`）

| 维度 | 条件 | 得分 |
|---|---|---|
| 声誉 | ≥ 80 / ≥ 60 | +2 / +1 |
| 市场占有率 | ≥ 35% / ≥ 20% | +2 / +1 |
| 总资产 | ≥ 150 万 / ≥ 80 万 | +2 / +1 |

| 总分 | 评级 |
|---|---|
| ≥ 5 | S |
| ≥ 4 | A |
| ≥ 2 | B |
| 其余 | C |

- 总资产 = 现金 + 车辆购置成本×0.8 + 仓库等级×5000 + 站点×3000
- 评级在结算面板（`GameOver.tscn`）展示

### 胜负判定（`GameManager._check_game_over()`）

| 条件 | 结果 |
|---|---|
| 现金 < -50000 | 失败（破产） |
| 生涯模式 && Day ≥ 20 && 评级 ∈ {S, A} | 胜利（称霸区域） |
| 其余 | 继续经营 |

- `game_over_emitted` 防重复触发；读档时自动重置
- `advance_day()` 在 game over 后不再推进，结算页静止

## 二、存档槽位系统

### 槽位模型

| 槽位 | 用途 |
|---|---|
| `slot_1` ~ `slot_9` | 手动/新建存档（最多 9 个） |
| `autosave` | 兼容旧版本保留 |

### 交互

- **主菜单 → 继续游戏**：打开存档槽位面板，列出所有槽位（公司名 / Day / 区域 / 保存时间），可读取或删除
- **主菜单 → 开始新游戏**：自动写入 `next_free_slot()`（不覆盖已有存档），并绑定为活跃槽位
- **游戏内保存**（顶栏 💾）：保存到当前活跃槽位
- **设置 → 存档**：立即保存（活跃槽位）、读取、删除任意槽位

### 实现

- `SaveManager`：`next_free_slot()` / `has_slot()` / `slot_label()` / `list_slots()` 等
- `GameManager.active_slot`：当前游戏绑定的槽位（`new_game` 重置为 autosave；`load_slot` 自动绑定）
- 读取存档后 `game_over_emitted` 重置，允许重新判定胜负

## 三、竞争系统（多对手）

- 对手池：环宇速运 / 极速物流 / 顺风快达 / 天舟速递（中英双语）
- 每 15 天出现一个新对手（最多 3 家），初始份额 6%~11%
- 对手每日自然扩张（份额 ×1.02）+ 积累资金
- **促销事件**：每日 12% 概率随机对手发起促销，玩家份额临时下降 2%~5%
- 玩家份额 = 1 − Σ对手份额（归一化 ≤ 0.95）
- 财务页签展示每个对手及其份额；`player_share()` 供 UI / 评级 / 教程共用

## 五、游戏内暂停菜单与确认弹窗（v0.6）

- **PauseMenu**（`src/ui/PauseMenu.gd`）：ESC 或顶栏 🏠 打开；半透明遮罩 + 居中卡片 + 图标按钮（继续/保存/设置/关于/主菜单）
- 打开时自动暂停（记录原倍速），关闭恢复
- 「主菜单」先弹确认框（`src/ui/ConfirmDialog.gd`）防误触丢进度
- 确认框为通用组件：`ask(title, message, on_confirm)`，任何误触风险操作（返回主菜单/删除存档等）可复用

## 六、成就系统（v0.6）

- 数据驱动：`src/data/achievements.json`（12 项：首车/车队/首单/50 单/枢纽/站点/团队/科研/百万资产/市占 45%/30 天/第二区域）
- `src/systems/AchievementSystem.gd`：`check()` 在 `_sync_all()` 自动调用，达成 → toast「🏅 成就解锁」+ 写入 `GameManager.achievements`（存档持久化）
- 成就面板：设置页新增「成就」页签，展示进度（x/12）与逐项解锁状态
- 指标：车辆数/累计配送/仓库/站点/员工/已解锁科技/总资产/市占%/天数/解锁区域数

## 七、竞争模型修正（v0.6）

- 开局即生成 1 家初始对手（份额 0.5~0.58），玩家以「挑战者」身份起步，避免玩家份额 100% 失真
- 对手扩张速率受玩家交付压制（每 50 单交付 ≈ 增速减半）
- 市占教程节（share10/share25）改为需 2/3 家对手在场才有意义
- 「市场霸主」成就门槛 30% → 45%（多对手竞争中才有含金量）
