# 市场宣传与推广（Marketing）

宣传系统决定**知名度（Awareness）**，知名度直接影响货量份额与客户获取成本，是需求侧的增长引擎。

## 一、核心指标：知名度

```
Awareness ∈ [0, 100]
货量系数 = f(Awareness)   // 单调递增，边际递减
```

- **知名度来源**：自然口碑（服务好慢慢涨）+ 主动投放（广告快速涨）+ 事件（舆情）。
- **知名度衰减**：长期不投入会缓慢回落（存在竞争市场）。
- **区域化**：知名度按区域（城市/区）独立计算，而非全国统一，体现"逐城攻占"策略。

## 二、推广渠道

| 渠道 | 成本 | 效果 | 适用阶段 |
|------|------|------|----------|
| 传单/地推 | 低 | 小范围、慢 | 起步 |
| 本地广告（公交/灯箱） | 中 | 单城市 | 成长 |
| 线上广告（搜索/信息流） | 中高 | 快、可定向 | 扩张 |
| 电视/户外大牌 | 高 | 大范围 | 成熟 |
| 促销活动（开业/满减） | 浮动 | 短期爆发 | 阶段冲刺 |
| 品牌事件（赞助/公益） | 高 | 长期口碑 | 品牌建设 |

## 三、促销活动（Campaign）

促销是短期拉量工具，与长期广告互补：

- **类型**：新站开业优惠、满减、首单立减、会员折扣、节日大促（双十一式）。
- **效果**：活动期内货量 ×1.2~2.0，但**客单价下降**，需权衡利润。
- **副作用**：促销期间货量激增可能**压垮运力**（爆仓、违约），是策略风险点。

## 四、价格策略（Pricing）

价格与宣传联动，构成需求侧的双杠杆：

- **统一定价 vs 分区定价**：可按线路/区域差异化定价。
- **价格弹性**：低价抢量、高价保利润；配合满意度权衡。
- **动态定价**（后期科技）：根据供需自动调整。

## 五、品牌与满意度

- **满意度（Satisfaction）**：由时效、破损率、价格、服务态度综合决定（见 [订单](/gameplay/order)）。
- **口碑循环**：满意度高 → 自然涨知名度 → 更多货量 → 需更大运力 → 若撑住则正向飞轮，撑不住则口碑崩盘。
- **舆情事件**：差评/投诉/负面新闻会打击知名度（见 [突发事件](/gameplay/events)）。

## 六、技术实现要点

- `MarketingSystem`（Autoload）维护"区域 → 知名度"字典 + 活跃活动列表。
- 知名度用**每日增量**公式更新，非逐帧：

```gdscript
# 每日知名度更新（示意）
func tick_day():
    for region in regions:
        var base = awareness[region]
        var decay = base * DECAY_RATE
        var growth = ad_effect[region] + promo_effect[region] + word_of_mouth(region)
        awareness[region] = clamp(base + growth - decay, 0, 100)
```

- 广告效果 = 渠道系数 × 预算，可在 UI 上滑杆调节预算 → 实时预览预估知名度/货量变化。
- 活动用 `Campaign` Resource 定义（时长、系数、成本），`CampaignManager` 驱动到期结算。
