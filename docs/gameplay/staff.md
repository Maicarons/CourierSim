# 员工与人力（Staff & HR）

员工系统为经营加入"人"的维度，是运力与效率的软性约束。

## 一、岗位类型

| 岗位 | 作用 | 对应设施 |
|------|------|----------|
| 司机 | 车辆必需，无司机车无法上路 | 车辆 |
| 分拣员 | 提升仓库吞吐 | 中转仓库 |
| 快递员 | 提升站点收派能力 | 站点 |
| 客服 | 提升满意度 | 公司级 |
| 管理岗 | 解锁高级功能/降本 | 公司级 |

## 二、招聘与技能

- **招聘**：从人才市场招聘，成本随岗位稀缺度浮动。
- **技能等级**：员工可培训升级（1~50 级或 1~10 级简化），高技能提升效率。
- **岗位增益**：
  - 高级分拣员 → 降低错发率、提升吞吐。
  - 资深司机 → 降低油耗/损耗、提升准点率。
  - 金牌快递员 → 提升派送速度与客户好评。

## 三、工资与满意度

- **工资**：按岗位/技能定，构成固定成本。
- **员工满意度**：工资、工作负荷、培训机会影响；满意度低 → 离职率上升、效率下降。
- **排班**：班次安排影响人力利用与成本（简化版可只做"编制数量"）。

## 四、编制上限

- 每类设施有 `staff_slots`（岗位数），员工需"入驻"设施才能生效。
- 扩张网络需同步扩编，否则运力/效率瓶颈卡在"没人"。

## 五、技术实现要点

- `StaffSystem`（Autoload）管理员工池 + 设施岗位分配。
- 员工是纯数据（Resource/Dictionary），不是场景节点。
- 效率系数统一汇总到各系统（吞吐 × 分拣效率、派送 × 快递员效率）。

```gdscript
# 员工数据（示意）
class_name Staff
extends Resource
@export var role: StaffRole
@export var skill: int = 1
@export var salary_per_day: int
@export var assigned_to: String = ""   # 设施 id
@export var morale: float = 100.0
```
