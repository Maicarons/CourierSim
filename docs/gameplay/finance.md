# 经济与财务（Economy & Finance）

> 适用版本：v0.12+ · 起始资金 ¥100 万 · 租赁 · 借贷 · 吨公里计价

经济系统是经营游戏的骨架。v0.12 全面重构：价格体系上调到"站点 20 万 / 仓 60 万 / 车 6~400 万"量级，
起始资金 30 万 → **100 万**，并新增**车辆租赁**与**银行借贷**两大周转手段。

## 一、收入（Revenue）

| 来源 | 说明 |
|---|---|
| 运费收入 | 核心。按**吨·公里**计价：`km × 吨数 × 45 × (1 + 重量×0.004) × 货种倍率`，保底 ¥800/单 |
| 货种溢价 | 冷链 1.6× / 医药 1.9× / 危险品 2.2× / 国际 2.4× |
| 区域加成 | 区域特色事件（如半导体出货潮）临时提升需求与收益 |

## 二、成本（Cost）

| 类别 | 明细 |
|---|---|
| 燃油 | 每段行程 `里程 × fuel_per_km`（面包车 0.6 / 货车 1.6 / 飞机 12 元/公里） |
| 维护费 | 车辆 `maintenance_per_day`（80~4000/天）+ 仓库 `level × 300/天` |
| 租赁费 | 租赁车辆每日扣 `lease_daily`（车价 × 2%） |
| 贷款利息 | 负债每日 `debt × 0.2%`（`LOAN_DAILY_RATE = 0.002`） |
| 一次性投入 | 购车 / 建站 20 万 / 建仓 60 万 / 营销升级 / 科技研发 / 广告 |

## 三、借贷系统（v0.12 新增）

```gdscript
# src/autoload/GameManager.gd（摘录）
var debt: int = 0                       # 当前负债
const LOAN_DAILY_RATE := 0.002          # 日息 0.2%（月息约 6%）

func max_loan() -> int:
    return max(0, int(net_worth() * 0.6) + int(reputation) * 8000)

func borrow(amount: int) -> bool        # 校验不超过 max_loan → debt += amount
func repay(amount: int) -> bool         # 偿还（可部分）
```

- **额度**：`max_loan = 净资产 × 60% + 声誉 × 8000`——信用越好、资产越多，能借越多。
- **入口**：财务面板「借款」按钮（一次借 max_loan 的 25%）、「还款」按钮（一次还 25% 负债）。
- 财务面板展示：现金 / 声誉 / 市占 / 负债 / 可借上限 / 最近流水。
- 破产判定沿用：现金 < −¥50,000 → 破产（生涯结束）。

## 四、车辆租赁（v0.12 新增）

- **日租 = 车价 × 2%**（面包车 ¥1,200/天，货车 ¥2,800/天）。
- 租赁车免首付，但不可出售；退租即归还。每日租金计入 `FinanceSystem.process_day`。
- 适用场景：前期现金紧张撑运力、临时补线、避免一次性大额支出。

## 五、成本与收益平衡（balance_sim 验证）

120 天 AI 长局基准（面包车策略）：

```
Day20  现金 充裕   交付 20+  市占 28%  声誉 58
Day60  现金 稳健   交付 108  市占 50%  声誉 65
Day100 现金 平稳   交付 210  市占 94%  声誉 71
Day120 → A 级通关、不破产（交付 325、市占 90%、声誉 100）
```

- 早期：100 万起步 + 赠仓 → 建 1 站（20 万）→ 租/买 2~3 车 → 订单开始滚动。
- 中期：网络扩张（更多站点）→ 订单量随站点数线性上升（`站点数 × 0.8/天`）→ 收入覆盖成本。
- 后期：市占蚕食机制（交付蚕食对手份额）→ 市占 90%+，可冲击 S 级。

## 六、技术实现要点

```gdscript
# src/systems/FinanceSystem.gd（摘录）
func process_day(game) -> void:
    # 1. 车辆维护 + 仓库运营
    # 2. 租赁车辆日租（vehicles 中 owned=false 的）
    # 3. 负债日息 debt × LOAN_DAILY_RATE
    # 4. 写入流水 ledger（category + label + amount + day）
```

- 金额全部用**整数（元）**存储，流水 `ledger` 数组记录每笔收支（财务面板最近 12 笔）。
- `EventBus.money_changed` / `debt_changed` 驱动顶栏与面板刷新。
