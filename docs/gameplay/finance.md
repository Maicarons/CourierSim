# 经济与财务（Economy & Finance）

经济系统是经营游戏的骨架，决定玩家"有多少钱、能干什么、会不会破产"。

## 一、收入（Revenue）

| 来源 | 说明 |
|------|------|
| 运费收入 | 核心，= 货单价格 × 完成量 |
| 增值服务 | 保价、代收货款、包装费 |
| 仓储服务 | 后期开放对外仓储（收取存储费） |
| 广告位/合作 | 少量，站点广告位出租 |

## 二、成本（Cost）

| 类别 | 明细 |
|------|------|
| 固定成本 | 站点/仓库日运营费、员工工资、车辆折旧 |
| 变动成本 | 燃油（随里程/油价）、维护、路桥费 |
| 一次性 | 购车、建站、建仓、研发、广告投放 |
| 隐性 | 积压罚金、违约赔款、破损赔付、贷款利息 |

## 三、财务报表

提供三类报表，支撑经营决策：

1. **损益表（P&L）**：收入 - 成本 = 利润，按日/月汇总。
2. **现金流表**：现金余额变化，防止"有利润没现金"。
3. **资产负载表**：车辆/建筑折旧、负债（贷款）。

## 四、贷款与信用（Borrowing & Credit）

延续 TransRoute 的金融模型：

- **信用评分（Credit Score）**：按时还款 + 盈利稳定 → 信用上升 → 可贷更多、利率更低。
- **贷款类型**：短期周转贷 / 长期设备贷 / 抵押贷。
- **破产**：资不抵债且无法偿还 → 破产清算（生涯结束，沙盒可继续或重开）。
- **融资租赁**：车辆分期，降低购车门槛但增加长期负债。

## 五、定价与利润曲线

- **单位经济**：`单均利润 = 运费 - (燃油+维护+人力+折旧分摊)`。
- **规模效应**：货量越大，固定成本摊薄越多，单均利润上升（鼓励扩张）。
- **边际递减**：过度扩张导致空驶、爆仓、违约，单均利润回落（抑制盲目扩张）。

## 六、技术实现要点

- `FinanceSystem`（Autoload）维护现金、信用、负债、日收支流水。
- 所有金额用**整数分（Integer cents）**存储，避免浮点误差。
- 每日 tick 结算：汇总当日收入/成本，更新现金与报表。

```gdscript
# 金额用整数分存储（示意）
var cash_cents: int = 0

func add_revenue(cents: int):
    cash_cents += cents

func add_cost(cents: int):
    cash_cents -= cents
    if cash_cents < 0:
        trigger_cash_shortage()
```
